# 🛡️ Home Cyber Lab

Laboratorio doméstico de ciberseguridad defensiva orientado a desarrollar experiencia práctica con Linux, Android/Termux, redes, automatización, monitoreo y análisis de eventos.

El objetivo del proyecto es construir progresivamente un entorno donde distintos dispositivos de mi propia red puedan funcionar como hosts, sensores y sistemas de análisis, permitiéndome experimentar con situaciones controladas y documentar tanto los resultados exitosos como las limitaciones encontradas.

## 🏗️ Entorno

- Lenovo G50-30 con Linux
- Motorola Android con Termux
- Red doméstica
- Python
- Git
- Splunk
- Herramientas Linux

## 🎯 Objetivos

- Comprender comunicaciones entre hosts.
- Generar y analizar eventos reales dentro de un entorno autorizado.
- Practicar análisis de logs.
- Crear baselines y detectar desviaciones.
- Automatizar tareas defensivas.
- Integrar progresivamente eventos con Splunk.
- Documentar investigaciones con metodología reproducible.
- Desarrollar habilidades aplicables a un entorno SOC.

## 📁 Estructura

`docs/` — arquitectura y documentación general.

`experiments/` — experimentos individuales del laboratorio.

`scripts/` — herramientas y automatizaciones propias.

`screenshots/` — evidencia técnica seleccionada y sanitizada.

`.github/` — automatizaciones de GitHub.

## 🔐 Seguridad y privacidad

Este laboratorio se realiza exclusivamente sobre dispositivos y redes propios o autorizados.

No se almacenan deliberadamente contraseñas, tokens, claves privadas ni otros secretos en el repositorio.

Las evidencias publicadas deben ser revisadas y sanitizadas antes de incorporarse al proyecto.
