# 📸 Evidencia técnica

Esta carpeta contiene capturas seleccionadas como evidencia de los experimentos realizados en el Home Cyber Lab.

## Criterios

Solo se conservan capturas que demuestren hitos técnicos relevantes, como:

- configuración validada;
- comunicación entre hosts;
- eventos y logs;
- detecciones;
- correcciones aplicadas;
- resultados finales.

No es necesario capturar cada comando ejecutado.

## Seguridad

Antes de publicar una captura se debe comprobar que no contenga:

- contraseñas;
- tokens;
- claves privadas;
- credenciales;
- datos personales;
- información sensible innecesaria.

Las capturas deben utilizar nombres descriptivos relacionados con el laboratorio correspondiente.
