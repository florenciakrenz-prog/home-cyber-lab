# 🛠️ Scripts

Esta carpeta contiene scripts y automatizaciones desarrollados para el Home Cyber Lab.

Los scripts podrán utilizarse para tareas como:

- recopilación de información del sistema;
- monitoreo defensivo;
- análisis de logs;
- detección de cambios;
- generación de eventos;
- automatización de tareas repetitivas;
- interacción controlada entre dispositivos del laboratorio.

Cada script deberá incluir una breve descripción de su propósito, requisitos y forma de uso.

## Seguridad

Los scripts están diseñados para ejecutarse exclusivamente sobre sistemas y redes propios o expresamente autorizados.

No se almacenarán credenciales, tokens, claves privadas ni otros secretos directamente en el código.
